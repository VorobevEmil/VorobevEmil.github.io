Chorus — LLM agent platform
Production, closed source · 2026

API server and admin panel for customer-support AI agents that talk to clients in messengers. Stateful sessions with conversation memory and hand-off to a human operator, retrieval-augmented generation over a knowledge base in PostgreSQL + pgvector, agent tools, versioned prompts with publishing, streaming responses, attachment and PDF understanding. Models are called through LiteLLM, so the provider can be swapped without code changes.

Built as a Vertical Slice Architecture service with architecture tests enforcing the boundaries; covered by quality audits and capacity testing before launch.
